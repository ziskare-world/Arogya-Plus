🚨 Real-time Emergency SOS & Telemetry Sequence

Real-time socket event loop between Patient GPS geocoding, Dispatcher routing, Ambulance Driver updates, and Doctor notification.

📡 Socket.IO Real-Time Engine 
sequenceDiagram
    autonumber
    actor Patient as 🧑 Patient (SOS)
    participant Browser as 📱 Leaflet / GPS
    participant API as 🌐 Express API
    participant Socket as ⚡ Socket.IO Engine
    participant Admin as 🏢 Dispatcher
    participant Driver as 🚑 Ambulance Driver

    Patient->>Browser: Click Emergency SOS / Book Ambulance
    Browser->>API: POST /api/ambulances (lat, lng, reason)
    API->>Socket: Emit 'emergency:new' & 'ambulance:requested'
    Socket-->>Admin: Real-time Dispatch Alert on Incident Map
    Admin->>API: POST /api/ambulances/:id/assign (Driver & Vehicle)
    API->>Socket: Emit 'ambulance:dispatched'
    Socket-->>Driver: Dispatch notification with Turn-by-Turn Route
    Socket-->>Patient: Assigned Driver Details & Initial ETA

    loop Every 3 Seconds
        Driver->>Socket: Emit 'ambulance:location_update' { lat, lng, speed }
        Socket-->>Patient: Smooth Interpolated Marker Movement
        Socket-->>Admin: Real-Time Fleet Telemetry
    end

    Driver->>API: PATCH /api/ambulances/:id/status ('arrived' -> 'completed')
    API->>Socket: Emit 'ambulance:completed'
    Socket-->>Patient: Emergency Resolved & Summary Displayed
